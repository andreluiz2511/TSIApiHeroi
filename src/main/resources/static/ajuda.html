HeroVerse

Guia de utilização da API de heróis

O que posso fazer com esta API?

A HeroVerse é uma API REST para gerenciar o universo de heróis. Ela permite trabalhar com heróis, poderes, fraquezas, perfis e equipes por meio de requisições HTTP.

  • Cadastrar novos registros.
  • Consultar registros existentes.
  • Pesquisar informações usando filtros disponíveis.
  • Atualizar dados cadastrados.
  • Excluir registros.
  • Relacionar heróis, poderes, fraquezas, perfis e equipes, conforme as regras de cada endpoint.

Como executar uma requisição?

  1. Abra a documentação pelo botão acima.
  2. Escolha o endpoint que deseja utilizar.
  3. Clique em Try it out.
  4. Preencha os parâmetros necessários.
  5. Se houver um corpo JSON, informe os dados solicitados.
  6. Clique em Execute.
  7. Confira a resposta e o código HTTP retornado.

Entendendo os métodos HTTP

  • GET: consulta informações.
  • POST: cria um registro ou executa uma ação.
  • PUT: atualiza informações.
  • DELETE: exclui um registro.

Os métodos disponíveis dependem de cada endpoint documentado no Swagger.

Como funciona a paginação?

A paginação permite consultar uma lista aos poucos, em vez de solicitar todos os registros de uma só vez.

page: indica o número da página. A primeira página normalmente é a página zero.

size: indica quantos registros você deseja receber por página.

Exemplo de consulta:

GET /heroi?page=0&size=10

Nesse exemplo, a requisição solicita a primeira página, com até 10 registros. O caminho /heroi é ilustrativo: confirme o caminho real na documentação.

Outros exemplos:

?page=0&size=5
?page=1&size=10
?page=2&size=10

Se houver 23 registros e forem solicitados 10 por página, a distribuição será de 10 registros na primeira página, 10 na segunda e 3 na terceira.

Importante: o tamanho máximo permitido depende da configuração do projeto. O parâmetro size representa a quantidade solicitada, mas não garante que todos os registros estarão disponíveis.

Códigos de resposta HTTP

  • 200 OK: requisição realizada com sucesso.
  • 201 Created: registro criado com sucesso, quando esse código é utilizado.
  • 204 No Content: operação concluída sem conteúdo de resposta.
  • 400 Bad Request: dados inválidos ou requisição incorreta.
  • 404 Not Found: registro não encontrado.
  • 500 Internal Server Error: erro interno inesperado no servidor.

Boas práticas

  • Confira os campos obrigatórios antes de enviar dados.
  • Utilize os IDs exigidos pelos endpoints relacionados.
  • Leia os exemplos de resposta disponíveis no Swagger.
  • Use a paginação ao consultar listas grandes.
  • Confira o código HTTP para identificar o resultado da operação.
